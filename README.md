# VirtuaLED

物理的な通知LEDを持たない端末のために、画面ロック中に「LEDが光っているように見える」疑似的な通知インジケーターを表示するAndroidアプリです。

## これは何か

画面をロックすると、実際には画面を消灯せず、黒一色の全画面上に小さなドット（またはカテゴリアイコン）を表示します。未読の通知が1件もない場合は何もせず端末は通常通りスリープし、保留中の通知が無くなった瞬間にこの疑似スリープ画面も自動的に終了します。

開発初期の内部名称は「NoLED-Revive」でした。かつて使えていた同種のサードパーティアプリが最近のAndroidバージョンで動作しなくなったことをきっかけに、独自に開発しています。

## 主な機能

- ドット/カテゴリアイコン（電話・メール・SNS・カレンダー・その他）表示
- インジケーター色のカスタマイズ
- 焼き付き防止（一定間隔でインジケーターの位置を自動移動）
- ユーザー登録キーワードによる重要度判定（該当時はアイコンを1.5倍表示）
- 近接センサー・低バッテリー・指定時間帯（クワイエットアワー）による自動停止
- 応答不可モード(DND)中の表示可否設定
- タップで通知内容のプレビュー表示（アプリ別の除外設定、既読通知の再通知抑制つき）
- 通知アクションボタンからのON/OFF切り替え
- 日本語・英語・簡体字中国語に対応

## 対応端末

Sharp AQUOS sense9、FCNT arrows We2 Plusの2機種でのみ動作確認しています。中華系メーカー端末（Xiaomi・Huawei・OPPO・vivo等）は動作保証対象外です。

## 技術構成

- Kotlin / Jetpack Compose
- `NotificationListenerService` による通知検出
- フォアグラウンドサービス（`specialUse`）
- フルスクリーン通知（full-screen-intent）経由で起動する全画面Activity（`setShowWhenLocked`/`setTurnScreenOn`）— セキュアロック画面の上にも描画可能
- minSdk 31（Android 12）/ targetSdk 35

## ビルド方法

```
./gradlew assembleDebug
```

生成された`app/build/outputs/apk/debug/app-debug.apk`を実機にインストールしてください。

## 配布状況

現状は個人利用・限定的なテスト配布のみを想定しています（サイドロード等）。Google Playでの一般公開は将来的な検討事項であり、現時点の目標ではありません。
